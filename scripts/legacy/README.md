# Código heredado 2024

`original_2024/` contiene una copia de los 141 archivos Python encontrados en
la carpeta `scripts/` del proyecto original al iniciar la migración. Se conserva
la misma estructura interna para facilitar la comparación.

Estos archivos no forman parte de la corrida. Una figura sólo queda habilitada
cuando su versión independiente se incorpora a `scripts/figures/`, cumple el
contrato `generate(context)` y se valida con sus datos oficiales.

No se deben corregir archivos dentro de `original_2024/`; cualquier cambio se
realiza en el script activo correspondiente.
