# Fuentes tipográficas

El proyecto está configurado para usar **Noto Sans**. Este paquete distribuible no incluye copias binarias `.ttf/.otf/.woff/.woff2`.

Para reproducir exactamente la tipografía en una instalación nueva, instala Noto Sans en el sistema o restaura localmente los archivos de fuente desde tu copia original del proyecto. El código conserva fallbacks para ejecución en entornos donde la fuente no esté disponible.
